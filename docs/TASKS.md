# Міндеттер мен жоспар

Әр қатысушы өз алгоритмін өзі жазады және қорғауда өзі түсіндіреді. Бастамас бұрын [`TUSINDIRME.md`](TUSINDIRME.md) оқыңыз. Орындалған тармақты `[x]` деп белгілеңіз.

## Жалпы жоспар

| Кезең | Не істейміз | Кім |
|---|---|---|
| 1-күн | Тақырыпты оқытушыға бекіту, репозиторийді GitHub-қа жүктеу, `docs/SPEC.md`-ны үшеуіміз бірге оқу | бәрі |
| 2–3-күн | Әркім өз алгоритмін жазады және тесттерін толтырады | әркім өзі |
| 4-күн | Үш модульді интерфейске қосу, «Қалай ойлады?» режимі | бәрі |
| 5-күн | Тексеру: телефонда ашу, қате енгізу, benchmark, скриншоттар | бәрі |
| 6-күн | Vercel-ге жариялау, README-ді толтыру, отчет, презентация, видео | бәрі |
| 7-күн | Пробная защита: бір-бірімізге сұрақ қою | бәрі |

Тапсыру мерзімі: [толтырыңыз]. Қорғау күні: [толтырыңыз].

- A\* BFS-тен неге аз ұяшық зерттейді, бірақ жол неге бірдей
- Байестің ықтималдығы жол құнына қалай әсер етеді

- шешім табылмаса, жүйе не істейді және неге адамдарды өзі бөлмейді
